# asado-website

## Google review sync

The home page review cards are updated from `data/reviews.json`.

`data/reviews.json` is generated by `.github/workflows/sync-google-reviews.yml`, which runs daily and can also be triggered manually from GitHub Actions.

Required GitHub secrets:

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REFRESH_TOKEN`
- `GBP_ACCOUNT_ID`
- `GBP_LOCATION_ID`

Local checks:

```powershell
node scripts/test-sync-google-reviews.mjs
node scripts/sync-google-reviews.mjs --dry-run --fixture data/reviews.json
```
